↗CHROME

Your stores, side by side.

Install the extension in desktop Chrome.

  1. Download and extract the Chrome ZIP.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the extracted folder.
  4. Sign in and set locations on store websites. Open the LowP side panel.

BEFORE YOU DOWNLOAD

A few useful details.

Do I need to sign in?

LowP doesn’t require its own account. Stores may need you to sign in and choose a delivery location to show products and prices for your area.

Are these the final checkout prices?

Results show listed product prices. Check pack sizes, delivery charges, taxes, availability, and offer eligibility at the store before ordering.

Where are the downloads hosted?

The Android APK, Chrome extension ZIP, release notes, and checksums are hosted in the public LowP-Public GitHub repository. Development source is maintained privately. The Chrome download includes the JavaScript, HTML, and CSS needed to run the extension.
